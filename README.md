## 🚀 Featured Projects

- **[Velox/Presto – Distance Function Registration Fix](https://github.com/facebookincubator/velox)** (Meta Open Source) — `C++ · Velox · Presto · CMake · GTest`
  `l2_squared`, `dot_product(real)`, and `cosine_similarity(real)` silently failed to register in default (non-FAISS) Velox builds, breaking real-column queries. Authored pure C++ fallback implementations for all four overloads, registered unconditionally regardless of `VELOX_ENABLE_FAISS`, and un-gated the matching unit tests. [PR](https://github.com/facebookincubator/velox/pull/18347)
- **[Stratum](https://github.com/prakriti31/stratum)** — Auto-Versioned, Time-Travel SQL Database — `Node.js · better-sqlite3 · chrono-node · React · Vite`
  A single-file embedded database that auto-versions every write and exposes time-travel SQL verbs (`AS OF`, `DIFF`, `HISTORY`, `BLAME`, `ROLLBACK`) via a CLI, REPL, and web UI. [Live Demo](https://stratum-client-ashy.vercel.app/)
- **[Wardwell](https://github.com/prakriti31/wardwell)** — Trust-Layer Marketplace for Caregivers — `Next.js · TypeScript · PostgreSQL/Prisma · Clerk · Checkr · Stripe`
  A two-sided caregiver marketplace built on continuous background monitoring, plain-language tiered verification, structured reference checks, and a trust-ops admin dashboard. [Live Demo](https://wardwell-six.vercel.app/)
